# AD Consulting Group Website

Portail officiel du consortium AD Consulting Group.

## Objectif

Créer un hub numérique présentant :

- les différents pôles du consortium ;
- les solutions et produits ;
- les services ;
- les réalisations ;
- les cas d’usage ;
- les ressources ;
- les moyens de contact et de prise de rendez-vous.

## Positionnement

Le site présente d’abord les besoins des visiteurs, puis les dirige vers les produits, services ou écosystèmes adaptés.

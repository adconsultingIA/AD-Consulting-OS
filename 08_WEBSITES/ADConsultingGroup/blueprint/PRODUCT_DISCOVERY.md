# Découverte des produits

Les produits doivent être visibles à plusieurs niveaux.

## Navigation globale

Un menu « Solutions » présente tous les produits.

## Navigation par besoin

- Gérer mes devis → DevisFlow
- Trouver des financements → DonorFlow
- Gérer mes réservations → BookingFlow
- Piloter avec mes données → InsightFlow
- Commander depuis l’Afrique → ColiAfrikFlow

## Page Écosystème

Une page présente l’ensemble des produits et leurs relations.

## Cartes sur l’accueil

Chaque produit possède :
- un nom ;
- une promesse ;
- un public cible ;
- trois fonctionnalités ;
- un bouton de découverte ;
- un statut : disponible, pilote ou à venir.

## Pages produit

Chaque produit dispose de sa propre page avec :
- problème ;
- solution ;
- bénéfices ;
- fonctionnalités ;
- captures ;
- plans ou modalités ;
- cas d’usage ;
- démonstration ;
- appel à l’action.

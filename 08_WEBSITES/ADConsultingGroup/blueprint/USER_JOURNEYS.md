# Parcours utilisateurs

## Dirigeant de PME

Besoin : améliorer sa gestion commerciale.

Parcours :
Accueil → Gérer mes devis → DevisFlow → Démonstration → Demander un essai.

## Association ou ONG

Besoin : organiser ses demandes de financement.

Parcours :
Accueil → Chercher des financements → DonorFlow → Cas d’usage → Prendre rendez-vous.

## Entreprise souhaitant automatiser

Besoin : réduire les tâches manuelles.

Parcours :
Accueil → Automatiser mon activité → Services IA et automatisation → Diagnostic.

## Client e-commerce en Afrique de l’Ouest

Besoin : acheter un produit non livré dans son pays.

Parcours :
Accueil → Commander un produit à l’international → ColiAfrikFlow → Coller un lien → Recevoir un devis.

## Recruteur ou partenaire

Besoin : comprendre les compétences et réalisations.

Parcours :
Accueil → Réalisations → Études de cas → Technologies → Contact.
